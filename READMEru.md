# Sahifalovchi

Языковые версии: [O‘zbekcha](README.md) · [English](READMEen.md)

Sahifalovchi — приложение для расчёта порядка страниц при печати книги в виде буклета на листах A4. Оно формирует отдельные списки для лицевой и обратной сторон листов и показывает наглядную схему раскладки.

Интерфейс доступен на узбекском, русском и английском языках. Приложение работает в браузере и не требует установки зависимостей для запуска из исходного кода.

## Как подготовить буклет

1. Откройте Sahifalovchi и выберите язык, если требуется.
2. В поле **«Всего страниц»** укажите общее число страниц книги.
3. Нажмите **«Рассчитать»**.
4. Проверьте число страниц и листов, затем сверьте пары страниц в списках и визуальном просмотре.
5. Скопируйте списки или сохраните их в TXT.
6. Разместите пары на листах A4 в альбомной ориентации и сначала напечатайте один пробный лист.

На одном листе A4 размещаются четыре страницы: по две на лицевой и обратной стороне. Поэтому количество страниц буклета должно быть кратно четырём. Минимум — 4 страницы. Если введённое число не кратно четырём, приложение округлит его вверх до ближайшего кратного и покажет уведомление. Например, для 10 страниц расчёт будет выполнен для 12 страниц — это 3 листа A4. Если в исходном документе нет добавленных страниц, предусмотрите для них пустые страницы.

## Как читать результаты

После расчёта появятся два списка:

- **Сторона 1** — пары для лицевой стороны листов.
- **Сторона 2** — пары для обратной стороны листов.

Каждая пара записана в формате `левая страница,правая страница`. Например, `12,1` означает, что на одной стороне листа слева размещается страница 12, а справа — страница 1. Пары на одинаковых позициях в двух списках относятся к одному и тому же листу.

Пример для 12 страниц при настройках по умолчанию:

| Лист | Лицевая сторона | Обратная сторона |
|---|---|---|
| 1 | `12,1` | `2,11` |
| 2 | `10,3` | `4,9` |
| 3 | `8,5` | `6,7` |

Первый лист — внешний лист буклета, следующие листы вкладываются внутрь него. После печати сложите листы пополам и вложите друг в друга в порядке списка.

## Настройки списков и порядка

- **«Каждую пару с новой строки»** переключает формат соответствующего списка. При включённой настройке каждая пара начинается с новой строки; настройка лицевой и обратной стороны независима.
- **«Обратный порядок для принтера»** меняет порядок пар во втором списке, не меняя страницы внутри пары. Настройка предназначена для порядка подачи листов принтером. Она включена по умолчанию и сохраняется в этом браузере.
- **«Обратить порядок листов»** меняет порядок листов в списках и визуальном просмотре. Используйте её, если этого требует ваш способ печати или укладки.
- Визуальный просмотр показывает лицевую и обратную стороны листов. Для скорости в нём отображается не более 200 листов; в списках для печати остаются все рассчитанные листы.
- Кнопка **«Копировать»** копирует список соответствующей стороны. Если в поле выделен фрагмент, будет скопирован только он. Можно также нажать непосредственно на поле списка.
- Кнопка **«Сохранить в TXT»** скачивает текстовый файл с обоими списками.

## Печать

Для печати по спискам приложения:

1. Выберите бумагу A4 и альбомную ориентацию.
2. Для каждой пары разместите первое число слева, второе — справа.
3. Напечатайте лицевые и обратные стороны на одних и тех же листах. Используйте двустороннюю печать, если её поддерживает принтер.
4. Перед печатью всего тиража сделайте пробную печать одного листа. Проверьте, что при перевороте бумаги обратная сторона не оказалась вверх ногами: направление переворота зависит от принтера и программы печати.
5. Сложите листы пополам и вложите один в другой: внешний лист должен остаться снаружи.

Вместо списков можно воспользоваться встроенной печатью буклета в Microsoft Word: **Макет → Поля → Настраиваемые поля → Несколько страниц → Брошюра**. Укажите бумагу A4, включите двустороннюю печать и сначала проверьте результат на одной пробной копии. В этом режиме Word сам рассчитывает порядок страниц, поэтому не смешивайте его с раскладкой из списков Sahifalovchi.

## Язык, тема и сохранение настроек

- В меню языка доступны узбекский (`O'Z`), русский (`RU`) и английский (`EN`).
- Переключатель темы меняет светлую и тёмную темы. При первом запуске используется системная тема.
- Выбранный язык, тема и настройка обратного порядка для принтера сохраняются в локальном хранилище браузера на этом устройстве.
- Ссылка **«Скачать»** открывает доступный установочный файл Windows. Android APK пока не предоставляется.

## Запуск из исходного кода

Это статическое веб-приложение. Чтобы запустить его локально:

1. Склонируйте репозиторий или скачайте его архив.
2. Откройте `index.html` в современном браузере.

Для проверки в локальном веб-сервере откройте корневую папку проекта через расширение Live Server в Visual Studio Code. В проекте нет шага сборки и установки npm-пакетов.

Для установки как PWA откройте сайт через HTTPS в браузере, который поддерживает установку веб-приложений, и воспользуйтесь командой установки в меню браузера. Service worker регистрируется на HTTPS-сайте или при запуске через `localhost`.

## Советы и ограничения

- Вводите число страниц исходной книги, а не число листов.
- Минимум для расчёта — 4 страницы; результат всегда будет кратен четырём.
- Если изменили число страниц или настройку порядка, проверьте обновлённые списки перед печатью.
- При двусторонней печати всегда сначала проверьте ориентацию обратной стороны на пробном листе.
- Толстую книгу может быть удобнее собирать из нескольких небольших блоков.
- Для надёжной работы приложения используйте актуальную версию браузера.
