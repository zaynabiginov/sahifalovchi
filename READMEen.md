# Sahifalovchi

Language versions: [Русский](READMEru.md) · [O‘zbekcha](README.md)

Sahifalovchi calculates page order for printing a book as a booklet on A4 sheets. It creates separate page lists for the front and back of each sheet and provides a visual layout preview.

The interface is available in Uzbek, Russian, and English. The app runs in a browser and requires no dependencies to launch from source.

## Preparing a booklet

1. Open Sahifalovchi and select a language if needed.
2. Enter the book's total page count in **“Total pages.”**
3. Select **“Calculate.”**
4. Check the page and sheet totals, then review the page pairs in the lists and visual preview.
5. Copy the lists or save them as a TXT file.
6. Arrange the pairs on A4 sheets in landscape orientation and print one test sheet first.

Each A4 sheet holds four book pages: two on the front and two on the back. Therefore, a booklet's page count must be divisible by four. The minimum is 4 pages. If the entered count is not divisible by four, the app rounds it up to the next multiple of four and displays a notice. For example, entering 10 pages calculates a 12-page booklet using 3 A4 sheets. Add blank pages for any pages missing from the source document.

## Reading the results

After calculation, two lists are generated:

- **Side 1** — pairs for the front of the sheets.
- **Side 2** — pairs for the back of the sheets.

Each pair uses the format `left page,right page`. For example, `12,1` means page 12 goes on the left and page 1 on the right of one side of a sheet. Pairs at the same position in both lists belong to the same physical sheet.

Example for 12 pages with the default settings:

| Sheet | Front | Back |
|---|---|---|
| 1 | `12,1` | `2,11` |
| 2 | `10,3` | `4,9` |
| 3 | `8,5` | `6,7` |

The first sheet is the booklet's outer sheet; the remaining sheets are nested inside it. After printing, fold the sheets in half and nest them in list order.

## List and order settings

- **“Show each pair on a new line”** changes the format of the corresponding list. When enabled, each pair starts on a new line. The front and back settings are independent.
- **“Reverse printer feed order”** reverses the order of pairs in the second list without swapping the pages within a pair. Use it to match the order in which your printer feeds sheets. It is enabled by default and saved in this browser.
- **“Reverse sheet order”** changes the sheet sequence in both lists and in the visual preview. Use it if required by your printing or stacking workflow.
- The visual preview shows the front and back of each sheet. To keep the page responsive, it displays at most 200 sheets; the print lists still contain every calculated sheet.
- **“Copy”** copies the list for the corresponding side. If text is selected, only the selection is copied. You can also click the list field to copy it.
- **“Save as TXT”** downloads a text file containing both lists.

## Printing

To print using the app's lists:

1. Select A4 paper and landscape orientation.
2. For each pair, place the first number on the left and the second on the right.
3. Print the front and back on the same sheets. Use duplex printing if your printer supports it.
4. Print one test sheet before printing the full run. Check that the back is not upside down after the paper is turned: the required flip direction depends on the printer and print software.
5. Fold the sheets in half and nest them together, keeping the outer sheet on the outside.

Alternatively, use Microsoft Word's built-in booklet printing: **Layout → Margins → Custom Margins → Multiple pages → Book fold**. Choose A4 paper, enable duplex printing, and print one test copy first. In this mode, Word calculates the page order itself, so do not combine it with the ordering generated by Sahifalovchi.

## Language, theme, and saved preferences

- The language menu offers Uzbek (`O'Z`), Russian (`RU`), and English (`EN`).
- The theme switch toggles between light and dark themes. The system theme is used by default.
- The selected language, theme, and reverse printer-feed setting are saved in this browser on this device.
- The **“Download”** link opens the available Windows installer. An Android APK is not currently available.

## Running from source

This is a static web app. To run it locally:

1. Clone the repository or download its archive.
2. Open `index.html` in a modern browser.

To test it with a local web server, open the project root using the Live Server extension in Visual Studio Code. The project has no build step and requires no npm packages.

To install it as a PWA, open the site over HTTPS in a browser that supports web app installation, then use the browser's install command. The service worker is registered on HTTPS or when running on `localhost`.

## Tips and limitations

- Enter the number of pages in the book, not the number of sheets.
- At least 4 pages are required; the result is always divisible by four.
- If you change the page count or order settings, review the updated lists before printing.
- For duplex printing, always check the back-side orientation on a test sheet first.
- A thick book may be easier to assemble as several smaller sections.
- Use an up-to-date browser for reliable operation.
